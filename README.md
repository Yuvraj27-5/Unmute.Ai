# Unmute.ai

An accessible communication app that translates sign-language gestures into text using a live camera feed. It helps bridge communication between sign-language users and non-signers through live camera recognition, quick phrase buttons, and on-screen text output.

## Features

- Live camera-based sign gesture recognition
- Text output for recognized gestures
- Quick phrase buttons for common communication needs
- Flutter-based cross-platform application

## Getting started

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Clone this repository:
   ```bash
   git clone https://github.com/Yuvraj27-5/Unmute.Ai.git
   cd Unmute.Ai
   ```
3. Install project dependencies:
   ```bash
   flutter pub get
   ```
4. Connect a supported device or start an emulator.
5. Run the application:
   ```bash
   flutter run
   ```
